Solmar City is an original open-world crime game that runs entirely in a desktop browser from static files — no server, no network, no build step. You are Milo Reyes, a driver-for-hire in the sun-soaked coastal city of Solmar Bay: eight blocks by eight of marina, old town, downtown towers and beachfront, with traffic to dodge, cars to borrow, pedestrians, a wanted level with police who answer it, and work from fixer Carmen Solis — fares, package runs and checkpoint hustles — while the Vane Syndicate watches from across the canal. Explore on foot or behind the wheel, keep an eye on the minimap, and try not to let the heat catch you.

## Run it

```
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. (Any static file server pointed at `game/` works just as well.)

## Controls

- **W A S D / arrow keys** — walk, or accelerate / brake / steer in a car
- **Shift** — run on foot
- **E** — get into / out of the nearest car
- **F** or **mouse click** — punch (on foot)
- **Space** — handbrake in a car
- **Mouse drag** — orbit the camera
- **L** — headlights
- **M** — mute / unmute sound
- **Esc** or **P** — pause
